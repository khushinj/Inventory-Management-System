# 📦 Inventory Management System

A **role-based inventory management web application** built to help businesses manage **warehouse and retail stock** efficiently.  
This system replaces unreliable Excel-based tracking with **real-time, centralized inventory control**.

## 🚀 Key Features

### 🔐 Role-Based Access Control
- Admin  
- Manager  
- Warehouse Staff  
- Retailer  
- Easily extendable to more roles  

---

### 📦 Inventory Tracking
- Track items by:
  - Design number  
  - Size  
  - Color  
- Add stock (production)  
- Deduct stock (sales)  
- Accurate quantity management  

---

### 🧾 Structured Data Entry
- Multiple forms for inventory, production, and sales  
- Eliminates duplicate and inconsistent records  

---

### 📊 Centralized Database
- Single source of truth for warehouse + retail  
- Real-time data consistency  

---
