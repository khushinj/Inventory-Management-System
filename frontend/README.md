# Inventory Management Frontend

The frontend for the Inventory Management System is built with Next.js, React, and Tailwind CSS.

## Local Development

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in a browser. The frontend expects the backend API to be available according to the configured environment settings.

## Production Build

```bash
npm run build
npm start
```

## Project Layout

- `app/` contains the application routes and page components.
- `lib/` contains shared frontend utilities.
- `public/` contains static assets.
